Prova pràctica · UD 1 i UD 2 (versió curta)¶

Mòdul: DWEC · Curs: 2026-27 · Durada: 1h 30 min · Puntuació: 10 punts

Context¶

Sistema per gestionar alumnes, professors, assignatures i notes. Cal depurar, corregir, provar i ampliar.

Baixa el projecte inicial.

Part 1 · Depura (3 punts)¶

Amb l'ajuda del depurador, completa la taula amb una línia per funció fent servir debug.js:

  • buscarAlumne()
  • matricular()
  • posarNota()
  • mitjana()
  • carregar()/desar()
# Funció/Mètode Esperat Observat Causa Correcció
1 buscarAlumne()
2 matricular()
3 posarNota()
4 mitjana()
5 carregar()/desar()

Part 2 · Corregeix (2 punts)¶

Modifica només els fitxers de src/. Respecta:

Fitxer Contracte
persona.js id, nom, cognoms. nomComplet() retorna "Cognoms, Nom".
alumne.js extends Persona. notes = {}. posarNota(assignaturaId, nota) valida entre 0 i 10 (inclosos). Si no, llança Error("Nota invàlida").
professor.js extends Persona. assignaturesImpartides = [].
assignatura.js id, codi, nom, curs, modul.
institut.js carregarAlumnes/Assignatures/Professors() amb try/catch: retornen col·leccions o [] si falla. desar() escriu dades simples. buscarAlumne(nomOCognom) parcial i insensible a majúscules/minúscules. donarAltaAssignatura() afegeix l'assignatura. matricular(alumneId, assignaturaId) valida existència, sense duplicats, no modifica res si falla. posarNota(alumneId, assignaturaId, nota). mitjana(alumneId) mitjana aritmètica, arrodonida a 2 decimals, retorna 0 si no té notes.

Utilitza const/let, ===/!==. Sense console.log a src/.

Part 3 · Proves unitàries (3 punts)¶

Escriu a tests/institut.test.js amb node:test i node:assert/strict. Prova almenys:

  • nomComplet: "Cognoms, Nom".
  • buscarAlumne: exacte, minúscules, parcial, sense resultats.
  • matricular: correcte, duplicat, alumne/assignatura inexistent (sense modificar si falla).
  • posarNota: vàlida (0-10), invàlida (<0 o >10).
  • mitjana: amb notes, sense notes, arrodoniment a 2 decimals.
  • Persistència: desar() + carregar(), fitxer inexistent, JSON invàlid.

Fes proves independents amb entorn temporal (fs.mkdtempSync) i neteja amb after() o try/finally.

Part 4 · Implementa codi (2 punts)¶

A Institut implementa només:

  1. llistarAlumnesMatriculats(assignaturaId) — Array nou amb alumnes matriculats. Si no existeix l'assignatura o no n'hi ha, retorna []. No modifica res.
  2. assignaturesDunAlumne(alumneId) — Array nou amb les Assignatura on l'alumne està matriculat. Si no en té cap, retorna [].
  3. informeAlumne(alumneId) — Retorna: 
    {
  alumne: { id, nomComplet },
  assignaturesMatriculades: ["DWEC", "DIW"], // codis o noms coherents
  notes: { 101: 7.5, 102: 6 }, // per assignaturaId
  mitjana: 6.75
}
    Si l'alumne no existeix, llança Error("Alumne no trobat"). Usa mitjana() per calcular-la.
