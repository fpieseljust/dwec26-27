Prova pràctica · UD 1 i UD 2¶

Mòdul: DWEC · Curs: 2026-27 · Durada: 2 hores · Puntuació: 10 punts

Nom i cognoms: _____ · Grup: _____

Context¶

Botiga El Just necessita un mòdul en Node.js per gestionar l'inventari. Tens un projecte que funciona parcialment i conté errors intencionats: has de depurar-los, corregir-los, provar-los i ampliar la funcionalitat.

Baixa el projecte inicial.

Condicions

  • No modifiques dades/inventari.json; usa còpies o fitxers temporals.
  • Cal aportar evidències del depurador (breakpoints i valors inspeccionats).

Part 1 · Depura (3 punts)¶

Completa la taula amb una línia per error:

  • valorTotal() i aplicarDescompte() — Compara els valors esperats i observats.
  • ProductePereixedor — Executa fins al constructor i copia l'excepció.
  • buscarPerNom(), retirar() i desar() — Prova "Teclat", "teclat", "clat", retirar(1, 999) i npm run debug:desar.
# Funció Esperat Observat Causa Correcció
1 valorTotal()
2 aplicarDescompte()
3 ProductePereixedor
4 buscarPerNom() / retirar()
5 desar() / carregar()

Evidències

Pots adjuntar captures del depurador o copiar els valors observats.

Part 2 · Corregeix (2 punts)¶

Corregeix els fitxers de src/:

Fitxer Contracte
producte.js valorEstoc = preu * estoc arredonit a 2 decimals; aplicarDescompte(percentatge) valida (0–100), aplica el descompte i arredona; toString() llegible
productePereixedor.js Crida super(...); estaCaducat() retorna true si diesPerCaducar <= 0; hereta la resta
inventari.js carregar() retorna Producte[] o [] si falta el fitxer o el JSON és invàlid; desar() escriu JSON; buscarPerNom() cerca parcial i insensible a majúscules; valorTotal() suma i arredona (0 si buit); retirar() valida i no muta l'estoc si falla; aplicarDescompteGlobal() descompta tots

Qualitat: const/let (mai var), ===/!== i cap console.log a src/.

Part 3 · Proves unitàries (3 punts)¶

Escriu les proves a tests/ amb node:test i node:assert/strict (mira l'exemple de tests/producte.test.js).

Àrea Casos mínims
valorTotal Buit i tres productes
aplicarDescompte 10 %, 0 %, 100 % i invàlid
buscarPerNom Exacte, minúscules, parcial i sense resultats
retirar Correcte, estoc insuficient i quantitat no positiva
ProductePereixedor Herència i caducitat certa/falsa
Persistència desar()+carregar(), fitxer inexistent i JSON invàlid
Extensions Una prova per mètode de la Part 4

Requisits: proves independents, entorn temporal (crearEntornTemporal() o fs.mkdtempSync), neteja amb t.after(...) o try/finally, i comprovació del valor retornat i dels efectes.

Part 4 · Amplia la funcionalitat (2 punts)¶

  1. Inventari.estocBaix(llindar = 5) (0,5) — Array nou amb estoc <= llindar, ordenat per estoc ascendent, sense modificar this.productes.
  2. Inventari.ordenarPerPreu() (0,5) — Array nou ordenat per preu ascendent, sense modificar this.productes.
  3. ProductePereixedor.aplicarDescompte() (0,5) — Si diesPerCaducar <= 3, afig un 20 % addicional (màxim 100 %); si no, crida super.aplicarDescompte(...).
  4. Inventari.generarInforme() (0,5) — Retorna { totalProductes, valorTotal, productesEstocBaix }, amb els noms dels productes d'estoc baix ordenats amb estocBaix().

Part 5 · Lliurament i avaluació¶

Lliura el projecte corregit, les proves i un informe.md amb la taula de la Part 1, una breu explicació de cada correcció i les decisions d'ampliació. npm test ha de passar sense errors.

Part Punts
1 · Depuració 3,0
2 · Correcció 2,0
3 · Proves 3,0
4 · Ampliació 2,0
Total 10,0

Penalitzacions: modificar inventari.json (−0,5) · no aportar evidències de depuració (−1,0) · proves no independents o amb fitxers temporals (−0,5) · npm test no passa (−1,0).

Annex · Comandes¶

npm test            # proves
npm run debug       # depurador
npm run debug:desar # persistència
