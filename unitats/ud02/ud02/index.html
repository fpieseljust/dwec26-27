1. Variables i tipus de dades¶

Declaració de variables¶

// const: no es pot reassignar (preferible)
const PI = 3.14159;

// let: es pot reassignar
let edat = 20;
edat = 21;

// var: antic, evitar-ho
var nom = "Ana"; // no utilitzar

Recomanació

Utilitza const per defecte. Canvia a let només si necessites reassignar el valor.

Tipus de dades primitives¶

Tipus Exemple Descripció
string "Hola" Text
number 42, 3.14 Nombre (enter o decimal)
boolean true, false Cert o fals
null null Absència de valor
undefined undefined Variable sense valor
bigint 9007199254740991n Enters molt grans
symbol Symbol('id') Identificador únic

Comprovar tipus¶

const nom = "Ana";
console.log(typeof nom); // "string"

const edat = 20;
console.log(typeof edat); // "number"

const actiu = true;
console.log(typeof actiu); // "boolean"

Conversió de tipus¶

// String a número
const num = Number("42");      // 42
const num2 = parseInt("42");   // 42
const num3 = parseFloat("3.14"); // 3.14

// Número a string
const text = String(42);       // "42"
const text2 = (42).toString(); // "42"

// A boolean
const cert = Boolean(1);       // true
const fals = Boolean(0);       // false
const fals2 = Boolean("");     // false

Plantilles de cadena (template literals)¶

const nom = "Ana";
const edat = 20;

// Forma antiga
const missatge1 = "Em dic " + nom + " i tinc " + edat + " anys.";

// Template literals (recomanat)
const missatge2 = `Em dic ${nom} i tinc ${edat} anys.`;

// Multilínia
const html = `
    <div>
        <h1>${nom}</h1>
        <p>Edat: ${edat}</p>
    </div>
`;

2. Operadors¶

Aritmètics¶

Operador Descripció Exemple
+ Suma 5 + 3 → 8
- Resta 5 - 3 → 2
* Multiplicació 5 * 3 → 15
/ Divisió 5 / 3 → 1.666...
% Mòdul (residu) 5 % 3 → 2
** Potència 5 ** 3 → 125

Assignació¶

Operador Exemple Equival a
= x = 5 x = 5
+= x += 3 x = x + 3
-= x -= 3 x = x - 3
*= x *= 3 x = x * 3
/= x /= 3 x = x / 3

Comparació¶

Operador Descripció Exemple
== Igual (amb conversió) "5" == 5 → true
=== Igual estricte (sense conversió) "5" === 5 → false
!= Diferent (amb conversió) "5" != 5 → false
!== Diferent estricte "5" !== 5 → true
> Major que 5 > 3 → true
< Menor que 5 < 3 → false
>= Major o igual 5 >= 5 → true
<= Menor o igual 5 <= 3 → false

Recomanació

Utilitza sempre === i !== per evitar errors de conversió.

Lògics¶

Operador Descripció Exemple
&& I (AND) true && false → false
|| O (OR) true \|\| false → true
! No (NOT) !true → false

Nullish coalescing¶

const valor = null;
const defecte = "valor per defecte";

const resultat = valor ?? defecte; // "valor per defecte"

// Diferència amb ||
const x = 0;
console.log(x || "defecte"); // "defecte" (0 és falsy)
console.log(x ?? "defecte"); // 0 (nullish coalescing només mira null/undefined)

3. Sentències condicionals¶

if / else if / else¶

const edat = 18;

if (edat >= 18) {
    console.log("Eres major d'edat");
} else if (edat >= 16) {
    console.log("Quasi major d'edat");
} else {
    console.log("Eres menor d'edat");
}

Operador ternari¶

const edat = 18;
const missatge = edat >= 18 ? "Major d'edat" : "Menor d'edat";

switch¶

const dia = "dilluns";

switch (dia) {
    case "dilluns":
        console.log("Dilluns de feina");
        break;
    case "divendres":
        console.log("Divendres, quasi cap de setmana!");
        break;
    case "dissabte":
    case "diumenge":
        console.log("Cap de setmana!");
        break;
    default:
        console.log("Dia laborable");
}

Opcional chaining¶

const usuari = {
    nom: "Ana",
    adreca: {
        carrer: "Carrer Major",
    },
};

// Si adreca fos undefined, causaria error
console.log(usuari.adreca?.carrer); // "Carrer Major"
console.log(usuari.telefon?.prefix); // undefined (sense error)

4. Bucles¶

for¶

for (let i = 0; i < 5; i++) {
    console.log(`Iteració ${i}`);
}

for...of (arrays)¶

const fruits = ["poma", "plàtan", "taronja"];

for (const fruita of fruits) {
    console.log(fruita);
}

for...in (objectes)¶

const persona = { nom: "Ana", edat: 20 };

for (const clau in persona) {
    console.log(`${clau}: ${persona[clau]}`);
}

while¶

let comptador = 0;
while (comptador < 5) {
    console.log(comptador);
    comptador++;
}

do...while¶

let comptador = 0;
do {
    console.log(comptador);
    comptador++;
} while (comptador < 5);

break i continue¶

// break: surt del bucle
for (let i = 0; i < 10; i++) {
    if (i === 5) break;
    console.log(i); // 0, 1, 2, 3, 4
}

// continue: salta a la següent iteració
for (let i = 0; i < 10; i++) {
    if (i % 2 === 0) continue;
    console.log(i); // 1, 3, 5, 7, 9
}

5. Funcions¶

Declaració de funció¶

function sumar(a, b) {
    return a + b;
}

const resultat = sumar(3, 5); // 8

Expressió de funció¶

const sumar = function(a, b) {
    return a + b;
};

Arrow functions (ES6+)¶

// Forma completa
const sumar = (a, b) => {
    return a + b;
};

// Forma abreujada (una sola instrucció)
const sumar = (a, b) => a + b;

// Un sol parèntesi
const quadrat = x => x * x;

// Sense paràmetres
const saludar = () => "Hola!";

Paràmetres per defecte¶

function saludar(nom = "Desconegut") {
    return `Hola, ${nom}!`;
}

saludar();        // "Hola, Desconegut!"
saludar("Ana");   // "Hola, Ana!"

Paràmetres rest¶

function sumar(...numeros) {
    return numeros.reduce((total, n) => total + n, 0);
}

sumar(1, 2, 3, 4); // 10

Destructuració de paràmetres¶

function crearUsuari({ nom, edat, email = "sense@email.com" }) {
    return { nom, edat, email };
}

crearUsuari({ nom: "Ana", edat: 20 });
// { nom: "Ana", edat: 20, email: "sense@email.com" }

6. Closures¶

Una closure és quan una funció "recorda" les variables del seu àmbit lexical fins i tot després que la funció hagi acabat.

function comptador() {
    let comptador = 0;

    return {
        incrementar() {
            comptador++;
        },
        obtenir() {
            return comptador;
        },
    };
}

const c = comptador();
c.incrementar();
c.incrementar();
console.log(c.obtenir()); // 2

Ús pràctic: funcions parcialment aplicades¶

function multiplicar(x) {
    return function(y) {
        return x * y;
    };
}

const doble = multiplicar(2);
const triple = multiplicar(3);

console.log(doble(5));  // 10
console.log(triple(5)); // 15

7. Orientació a objectes¶

Creació d'objectes¶

// Objecte literal
const cotxe = {
    marca: "Seat",
    model: "Ibiza",
    any: 2020,
    arrancar() {
        console.log(`${this.marca} ${this.model} ha arrancat`);
    },
};

cotxe.arrancar(); // "Seat Ibiza ha arrancat"

Classes¶

class Cotxe {
    // Constructor
    constructor(marca, model, any) {
        this.marca = marca;
        this.model = model;
        this.any = any;
        this._arrancat = false; // propietat privada (convenció)
    }

    // Mètodes
    arrancar() {
        this._arrancat = true;
        console.log(`${this.marca} ${this.model} ha arrancat`);
    }

    aturar() {
        this._arrancat = false;
        console.log(`${this.marca} ${this.model} s'ha aturat`);
    }

    // Getter
    get info() {
        return `${this.marca} ${this.model} (${this.any})`;
    }

    // Setter
    set anySetter(nouAny) {
        if (nouAny > 1885) {
            this.any = nouAny;
        }
    }
}

const cotxe = new Cotxe("Seat", "Ibiza", 2020);
cotxe.arrancar(); // "Seat Ibiza ha arrancat"
console.log(cotxe.info); // "Seat Ibiza (2020)"

Herència¶

class Vehicle {
    constructor(marca, velocitatMaxima) {
        this.marca = marca;
        this.velocitatMaxima = velocitatMaxima;
        this.velocitatActual = 0;
    }

    accelerar(increment) {
        this.velocitatActual = Math.min(
            this.velocitatActual + increment,
            this.velocitatMaxima
        );
    }

    frenar(decrement) {
        this.velocitatActual = Math.max(
            this.velocitatActual - decrement,
            0
        );
    }
}

class Cotxe extends Vehicle {
    constructor(marca, velocitatMaxima, portes) {
        super(marca, velocitatMaxima);
        this.portes = portes;
    }

    obirPortes() {
        console.log("Portes obertes");
    }
}

const cotxe = new Cotxe("BMW", 250, 5);
cotxe.accelerar(100);
console.log(cotxe.velocitatActual); // 100

Mètodes estàtics¶

class Calculadora {
    static sumar(a, b) {
        return a + b;
    }

    static restar(a, b) {
        return a - b;
    }
}

Calculadora.sumar(3, 5); // 8 (no cal crear instància)

8. JSON¶

JSON (JavaScript Object Notation) és el format d'intercanvi de dades per defecte a la web.

Sintaxi¶

const producte = {
    id: 1,
    nom: "Llibre de JavaScript",
    preu: 29.99,
    enStock: true,
    etiquetes: ["programació", "web"],
    autor: {
        nom: "John Doe",
        email: "john@example.com",
    },
};

Convertir a JSON¶

const jsonString = JSON.stringify(producte);
console.log(jsonString);
// '{"id":1,"nom":"Llibre de JavaScript","preu":29.99,...}'

// Amb format llegible
JSON.stringify(producte, null, 2);

Convertir de JSON¶

const jsonString = '{"id":1,"nom":"Llibre","preu":29.99}';
const objecte = JSON.parse(jsonString);

console.log(objecte.nom); // "Llibre"

Errors comuns¶

// Error: propietats amb cometes simples
const obj = { nom: 'Ana' }; // Funciona

// Error: cometes dobles en claus
const obj2 = { "nom": "Ana" }; // Funciona

// Error:Sense cometes en claus
const obj3 = { nom: "Ana" }; // Funciona (shorthand)

// Error: funcions no es poden serialitzar
const obj4 = {
    nom: "Ana",
    saludar() { return "Hola"; },
};
JSON.stringify(obj4); // {"nom":"Ana"} (la funció s'elimina)

9. Mòduls¶

Exportacions¶

// utils.js

// Exportació individual
export const PI = 3.14159;

export function sumar(a, b) {
    return a + b;
}

export class Calculadora {
    // ...
}

// Exportació per defecte (un sol element per fitxer)
export default function saludar(nom) {
    return `Hola, ${nom}!`;
}

Importacions¶

// app.js

// Importar exportació per defecte
import saludar from "./utils.js";

// Importar exportacions nombrades
import { PI, sumar, Calculadora } from "./utils.js";

// Importar tot
import * as Utils from "./utils.js";
Utils.PI; // 3.14159

// Renombrar
import { sumar as suma } from "./utils.js";

Mòduls dinàmics¶

// Carregar un mòdul condicionalment
async function carregarModul() {
    if (necessitoCalculadora) {
        const { Calculadora } = await import("./utils.js");
        const calc = new Calculadora();
    }
}

  • Tota la interacció és per consola (prompt, alert)

Pràctica 2.4 — Biblioteca de funcions

Crea un fitxer utils.js amb les seguents funcions exportades:

  2. restar(a, b) — retorna la resta

  4. dividir(a, b) — retorna la divisió (amb control d'errors)

  6. factorial(n) — retorna el factorial
  7. ordenarArray(array) — retorna un array ordenat

Importa-les a app.js i prova-les amb la consola.
